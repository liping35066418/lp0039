## 1. 产品概述

网速雷达（SpeedRadar）是一款面向前端工程师与运维人员的综合测速与前端性能检测工具。通过本地 8679 端口后端服务执行测速运算与数据统计，前端提供实时网速波动曲线、页面性能指标分析、资源加载清单与异常标记，支持多轮重复测试、历史报告存档、数据对比分析及一键导出，解决前端工程化场景下网络质量诊断与性能瓶颈定位的痛点。

- 目标用户：前端开发者、QA 工程师、运维人员
- 核心价值：一站式网络测速 + 前端性能检测，数据可追溯、可对比、可导出

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 默认用户 | 无需注册 | 使用全部测速与性能检测功能 |

### 2.2 功能模块

1. **测速面板页**：网络测速仪表盘、实时曲线、延迟与丢包检测
2. **性能检测页**：首屏加载、资源加载、脚本执行耗时、资源清单与异常标记
3. **历史报告页**：测试记录列表、多轮数据对比分析、报告导出
4. **长时监测页**：长时任务状态管理、后台保活、实时状态追踪

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 测速面板页 | 下载测速 | 通过后端生成可变大小数据块，前端下载并实时计算下载速率，动态绘制下载速度波动曲线 |
| 测速面板页 | 上传测速 | 前端生成指定大小随机数据上传至后端，实时计算上传速率，动态绘制上传速度波动曲线 |
| 测速面板页 | 延迟检测 | 连续向后端发送 ICMP 模拟 Ping 请求，统计 RTT 最小/平均/最大/抖动值，绘制延迟波动图 |
| 测速面板页 | 丢包率检测 | 发送多轮探测包统计丢包率，标记网络不稳定时段 |
| 测速面板页 | 综合评分 | 基于下载/上传/延迟/丢包四维指标加权计算综合网络质量评分（0-100） |
| 性能检测页 | 首屏加载分析 | 采集 FCP、LCP、CLS 等 Core Web Vitals 指标，展示首屏加载时间线 |
| 性能检测页 | 资源加载清单 | 列出所有静态资源（JS/CSS/图片/字体等）与接口请求的加载耗时、体积、状态码，标记异常项（超时、失败、体积过大） |
| 性能检测页 | 脚本执行耗时 | 统计各脚本解析、编译、执行耗时，识别长任务（Long Task） |
| 性能检测页 | 一键检测 | 触发全量性能检测，自动刷新页面并采集 Performance API 数据 |
| 历史报告页 | 测试记录列表 | 展示所有历史测试记录，含时间、类型、评分、状态，支持筛选与搜索 |
| 历史报告页 | 数据对比分析 | 选择2-4条历史记录进行指标对比，展示雷达图与差异表格 |
| 历史报告页 | 报告导出 | 一键导出当前报告为 JSON/CSV 格式文件 |
| 长时监测页 | 任务创建 | 配置监测时长、间隔、目标地址，创建长时监测任务 |
| 长时监测页 | 状态管理 | 展示运行中/已完成/失败任务列表，支持暂停/恢复/取消操作 |
| 长时监测页 | 后台保活 | 使用 Web Worker + Service Worker 保活机制，确保长时任务不中断 |
| 长时监测页 | 实时图表 | 长时监测期间实时绘制网速/延迟趋势图 |

## 3. 核心流程

### 3.1 网络测速流程

用户进入测速面板 → 点击「开始测速」→ 前端依次执行延迟检测→下载测速→上传测速→丢包检测 → 实时更新曲线与数值 → 计算综合评分 → 自动保存测试报告至后端

```mermaid
flowchart TD
    "用户点击开始测速" --> "延迟检测阶段"
    "延迟检测阶段" --> "下载测速阶段"
    "下载测速阶段" --> "上传测速阶段"
    "上传测速阶段" --> "丢包检测阶段"
    "丢包检测阶段" --> "计算综合评分"
    "计算综合评分" --> "保存报告至后端"
    "保存报告至后端" --> "展示结果与曲线"
```

### 3.2 性能检测流程

用户进入性能检测页 → 点击「一键检测」→ 页面自动刷新并注入采集脚本 → 采集 Performance API 数据 → 分析资源加载/脚本执行/首屏指标 → 展示结果清单并标记异常

```mermaid

    "用户点击一键检测" --> "注入采集脚本"
    "注入采集脚本" --> "页面刷新并采集"
    "页面刷新并采集" --> "解析Performance数据"
    "解析Performance数据" --> "分析首屏指标"
    "解析Performance数据" --> "分析资源清单"
    "解析Performance数据" --> "分析脚本耗时"
    "分析首屏指标" --> "标记异常项"
    "分析资源清单" --> "标记异常项"
    "分析脚本耗时" --> "标记异常项"
    "标记异常项" --> "展示完整报告"
```

### 3.3 长时监测流程

用户配置监测参数 → 创建监测任务 → Web Worker 执行定时探测 → Service Worker 保活 → 实时更新趋势图 → 任务完成/用户停止 → 生成完整报告

```mermaid

    "Web Worker定时探测" --> "实时更新趋势图"
    "Service Worker保活" --> "网络波动重试"
    "网络波动重试" --> "实时更新趋势图"
    "实时更新趋势图" --> "任务完成或用户停止"
    "任务完成或用户停止" --> "生成完整报告"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主题方向**：科技感深色仪表盘风格，偏向前端工程化工具的工业美学
- **主色调**：深色背景（#0a0e1a）+ 青绿色强调（#00f5d4）+ 橙色告警（#ff6b35）
- **辅助色**：深蓝卡片（#111827）、中灰文字（#9ca3af）、红色异常（#ef4444）
- **字体**：JetBrains Mono（数据/代码）+ Noto Sans SC（中文界面），突出数据可读性
- **按钮风格**：圆角微凸，主操作用青绿渐变，危险操作用橙红色
- **布局风格**：左侧固定导航 + 右侧内容区，卡片式模块布局
- **图标风格**：线性图标，2px 描边，与数据可视化风格统一
- **动效**：测速时仪表盘指针旋转动画、数值跳动、曲线实时绘制、脉冲指示灯

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 测速面板页 | 速度仪表盘 | 圆形仪表盘组件，指针动态旋转，中央显示当前速率数值与单位，渐变色弧线从绿到红 |
| 测速面板页 | 实时曲线图 | Canvas 绘制的折线图，X轴时间、Y轴速率，曲线下方渐变填充，青绿色主线 |
| 测速面板页 | 指标卡片 | 四宫格卡片展示下载/上传/延迟/丢包，带图标、数值、单位、趋势箭头 |
| 测速面板页 | 综合评分 | 环形进度条，0-100分，颜色随分数变化（红→黄→绿），中央显示分数 |
| 性能检测页 | Web Vitals 卡片 | 三个指标卡片（FCP/LCP/CLS），带颜色状态指示（好/需改进/差） |
| 性能检测页 | 资源加载清单 | 表格组件，列含名称/类型/体积/耗时/状态，异常行红色背景标记，可排序可筛选 |
| 性能检测页 | 脚本耗时条形图 | 横向堆叠条形图，展示各脚本解析/编译/执行耗时占比 |
| 历史报告页 | 报告列表 | 带搜索筛选的列表，每行含时间/类型/评分/状态标签，支持多选 |
| 历史报告页 | 对比雷达图 | Canvas 雷达图，5维指标对比所选记录，图例区分不同颜色 |
| 长时监测页 | 任务列表 | 卡片式列表，每张卡片含任务名/进度条/状态指示灯/操作按钮 |
| 长时监测页 | 实时趋势图 | 长滚动折线图，支持缩放与平移，标注异常时间点 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px 为最佳体验
- 1024-1280px 区间卡片布局自适应收缩
- 移动端（<768px）导航栏折叠为底部标签栏，卡片单列排列

### 4.4 动效设计

- 页面加载：模块依次淡入滑入，stagger 100ms
- 测速进行中：仪表盘指针旋转、数值跳动、脉冲指示灯闪烁、曲线实时绘制
- 状态切换：卡片悬停微缩放 + 阴影加深，按钮点击水波纹
- 数据更新：数字滚动动画（countUp），图表平滑过渡
- 异常提示：红色脉冲光晕 + 抖动动画
